AD Code Registration for Exporters: Why It's Required at Every Port

BuyGenix Solutions Team · 5 min read

Many first-time exporters are surprised to learn that having an IEC and GST registration still isn't enough to actually clear a shipment — customs will also ask for a registered AD Code at the specific port you're shipping from. Here's what it is and why it trips up so many new exporters.

What is an AD Code and Why It's Mandatory for Exports

An AD Code (Authorized Dealer Code) is a 14-digit code issued by your bank, identifying the branch that will handle your foreign exchange transactions for exports. Customs requires this code to be registered before your shipping bill can be filed — without it, your goods simply cannot be cleared for export, no matter how complete your other documentation is.

Why You Need AD Code Registered at Every Port

Here's the detail that catches exporters off guard: an AD Code registered at one port is not automatically valid at another. If you ship from Mumbai port one month and switch to Nhava Sheva or an airport the next, you need to register your AD Code separately at each new port through ICEGATE before you can file a shipping bill from there. Exporters who use multiple ports or freight forwarders across different cities need to plan for this in advance to avoid last-minute shipment delays.

Documents Required for AD Code Registration

  • AD Code letter issued by your bank on its official letterhead
  • GST registration certificate
  • IEC (Import Export Code) certificate
  • PAN card of the business
  • Bank account details / cancelled cheque
  • Digital Signature Certificate (DSC) of the authorized signatory

Step-by-Step AD Code Registration Process on ICEGATE

  • Step 1: Request an AD Code letter from your bank, confirming the branch handling your export forex transactions.
  • Step 2: Register or log in to your ICEGATE account.
  • Step 3: Submit the AD Code registration request for the specific port, along with the required documents, verified using your DSC.
  • Step 4: Once approved by Customs at that port, your AD Code is linked and you can begin filing shipping bills from that location.

Since this registration is port-specific, it's worth registering your AD Code at every port you're likely to use — including nearby alternatives — well before you need to actually ship, rather than discovering the gap when a shipment is already booked.
